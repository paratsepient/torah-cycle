# Збережені налаштування видання

Актуальне оформлення зафіксовано 7 жовтня 2026 року. Воно застосовується до всіх опублікованих глав і циклів автоматично, включно з наступними матеріалами. Це налаштування самого проєкту, а не окрема тема Берешит.

## Оформлення

- Темний фон `#090a08`, основний текст `#f1ede5`, приглушений текст `#aaa79e`, золотий акцент `#c6a573`.
- Локальні шрифти: Source Serif 4 для назв і основного тексту, Manrope для підписів, Noto Serif Hebrew для івриту.
- Фон обкладинки — власне фото глави. Нижня картка й кнопка архіву мають скло, світлу обводку та заокруглення.
- Назва глави показується один раз великим заголовком. Посилання на читання розташоване під її правим краєм, близько до напису івритом. Його стиль відповідає підпису «Сутність».
- Поточне позиціювання: блок назви опущений на 28 px, на мобільному — на 20 px; сам заголовок піднятий на 10 px; посилання має `top: calc(100% - .5rem)`. Використовуй спільні правила, не налаштовуй їх окремо для кожної глави.
- «Читати далі» — текстове посилання після сутності. Смужка дат і окрема кнопка читання прибрані.
- Емблема — геометрична золота зірка Давида з мінорою. Звичайний розмір у шапці: 42 px, мобільний: 36 px; проміжок до назви сайту — 8 px. На великих екранах діє окреме масштабування.
- Кнопка архіву містить тільки іконку меню. У шапці архіву — «Читаємо на цьому тижні» та актуальна назва, без окремої картки й дублю івритом.
- Золотий перелив картки запускається один раз за наведення. Новий запуск можливий після відведення курсора. Частинка зі шлейфом діє для точного курсора; reduced motion вимикає рух.
- Читання відкривається у спільному діалозі з прогресом під шапкою, без нижнього footer та позначки часу читання. Архів також має прогрес під шапкою.

## Адаптивність

- До 760 px: повна ширина картки, мобільні відступи, заголовок `clamp(2.75rem, 12.75vw, 6rem)`.
- Від 761 до 1000 px: картка займає всю доступну ширину між відступами сторінки.
- Від 1800 px: спільні правила для широких і 4K екранів масштабують картку, шапку, типографіку, діалог читання та архів. Не обмежуй такі сторінки стандартною карткою 790 px.
- Довгі назви й нові фотографії можуть вимагати перегляду на різних ширинах. Виправляй спільну композицію за необхідності, не додавай випадкові винятки для окремих назв.

## Нова глава

1. Скопіюй `_template.md` у `src/content/parashot/YEAR/SLUG.md`.
2. Заповни назви, порядок, перевірені дати, місце читання, сутність та питання. `readingUrl` веде на відповідний початковий розділ українського перекладу Bible.com, наприклад `https://www.bible.com/uk/bible/3786/GEN.23.CUV`.
3. Додай фото у `public/images/parashot/YEAR/SLUG/cover.webp` та змістовний `heroAlt`. Для дуже великих екранів бажане джерело високої роздільності; збільшення маленького фото не додає деталей.
4. Заповни `shareDescription`: стислий опис до 180 символів для месенджерів. Якщо поле відсутнє, використовується сутність.
5. Використовуй три розділи шаблону: «Про що ця глава», «Оповідь», «Сьогодні». «Питання тижня» додається з `reflectionQuestions`, тому його не потрібно дублювати в Markdown.
6. Готовий матеріал познач `published: true`, `draft: false`. До готовності залишай чернеткою; наявні записи `published: false`, `draft: false` використовуються як сторінки «Скоро».
7. Збірка `npm run build` створює responsive-фото та `share-v2.jpg` 1200×630 у спільному стилі. Заголовок прев’ю: «Назва · Тижнева глава Тори».

Нова глава автоматично отримує всі спільні налаштування через маршрути Astro. Створювати окремий layout, CSS або вручну копіювати дизайн Берешит не потрібно. Перед публікацією виконай `npm run check` і `npm run build`; календарні зміни перевіряються `npm test`.
