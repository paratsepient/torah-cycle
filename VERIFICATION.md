# Перевірка версії 1.0

Перевірено 4 жовтня 2026 року.

- `npm run check`: 0 помилок, 0 попереджень, 0 підказок.
- `npm test`: 6/6 календарних перевірок пройшли.
- `npm run build`: статична збірка успішна; головна, 4 короткі адреси, 4 річні адреси, sitemap та robots.
- Chromium: усі чотири матеріали завантажуються, фото відображаються, помилок сторінки або HTTP немає.
- Ширини 320, 390, 768, 1440 px: горизонтального переповнення немає.
- Архів: відкриття, один розгорнутий accordion, перехід до статті, Esc, повернення фокусу, Tab усередині modal — пройдено.
- `prefers-reduced-motion`: анімація hero вимикається.
- GitHub Pages build із префіксом `/torah-cycle/`: перевірено 121 внутрішнє посилання/ресурс і canonical. Усі ведуть у правильну папку.
- Окремий HTML-перегляд: відкриття локального файла, drawer і перехід між матеріалами пройдено.
- Hero WebP: 207–392 KB. Автоматично створено responsive-копії та OpenGraph 1200×630.

Скріншоти Chromium додаються до ZIP у папці `screenshots/`.
