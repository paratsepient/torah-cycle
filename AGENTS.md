# Цикл Тори: правила проєкту

Перед додаванням або публікацією нової глави прочитай `docs/PROJECT_SETTINGS.md` та використовуй `src/content/parashot/_template.md`.

Поточне оформлення є спільним для всіх глав і років. Зберігай його при роботі з матеріалами: змінюй текст, metadata та зображення через Markdown, а не копіюй сторінки чи стилі. Використовуй `ParashaLayout.astro`, спільні компоненти та `global.css`. Зміни оформлення роби лише в межах запиту користувача.

Не повертай прибрані елементи: декоративний номер за назвою, дубль назви над заголовком, смугу дат на обкладинці, кнопку «Читати», зайву картку поточної глави в архіві, верхню позначку часу читання чи footer у вікні читання.

Для нових глав збережи нову емблему, ефекти скла, один перелив за наведення, золоту частинку курсора, прогрес читання/архіву та адаптивні правила, включно з планшетами й 4K. Підтримуй reduced motion та клавіатурну навігацію.

Публікація в мережу та Git push потребують авторизації користувача в поточній розмові. Збереження матеріалу у файлах саме по собі не означає публікацію.
